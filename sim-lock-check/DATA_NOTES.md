# データ更新メモ（2021年10月以降の機種追加）

## 判定の考え方
出荷時のSIMロック有無は、各キャリアの「ロックなし販売」開始日で判定している。

| キャリア | ロックなしで販売された機種 |
|---|---|
| ドコモ | 2021/8/27以降に発売 |
| au・UQ | 2021/10/1以降に発売 |
| ソフトバンク・ワイモバイル | 2021/10/1以降に発売（2021/5/12以降の購入分は解除済で渡し） |
| 楽天モバイル | 全機種ロックなし |
| iPhone 13（2021/9/24発売） | 4キャリアとも発売時からロックなし |

## 型番の確認方法
- 各キャリアの公式サイト（ドコモ・au・ソフトバンク・ワイモバイル・楽天・サムスン・ソニー・シャープ）や価格サイトの検索結果で、機種名と型番が一致したものだけを記載した。
- 確認できなかった型番は空欄（一覧では「—」）にしている。機種名では検索できる。
- 公式サイトへ直接アクセスできない環境のため、検索結果の記載で確認している。**ドコモ・auは公式ページで一件ずつ再確認するのが望ましい**。

## 既存データの訂正
- **Galaxy A22 5G**：au・UQでの販売は無く、ドコモ（SC-56B、2021/12/2発売・ロックなし）のみ。以前の「au・UQ・ロックあり」は誤り。
- **BASIO active / active2**：京セラ製ではなくシャープ製（au SHG09／SHG12、ロックなし）。以前の「京セラ・KYV4x系・ロックあり」は誤り。UQでの取り扱いは確認できず削除。
- **OPPO A55s 5G**：取り扱いはソフトバンク（A102OP）と楽天モバイルで、au・UQでの販売は無し（2021/11/26発売でロックなし）。
- **au KYG04**：BASIO active3（京セラ製、2025年4月発売）と判明。同じく KYG02＝DIGNO SX3、KYG03＝TORQUE G06。
- **OPPO A5 2020**：auでの販売は無く（OPG01はFind X2 Pro）、UQモバイルの取り扱い。
- **らくらくスマートフォン4**：型番は F-04J（F-04K は arrows Be）。
- **Xperia Ace（初代）**：ワイモバイル版は存在せず削除。**AQUOS sense3**：ワイモバイル版（他機種と型番が重複）を削除。**arrows U**：ソフトバンク版（801FJ）に訂正。
- **TORQUE 5G（au KYG01）**：2021年11月発売のためロックなし。

## 旧データ（2021年以前）について
2021年以前の機種は以前の資料をもとにしたもので、今回の再確認は一部のみです。上記のような誤りが他にも残っている可能性があるため、現場で使う前に確認できたものから順に見直してください。

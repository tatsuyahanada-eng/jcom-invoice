# データ更新メモ（2021年10月以降の機種追加）

## J:COMモバイル「動作確認端末チェッカー」の取り込み（2026年9月版・PDF）
- メーカー別・購入キャリア別（SIMフリー／docomo／au／SoftBank／UQ／Y!mobile／楽天モバイル）の機種名と型番 **1,144件** を取り込みました（`tools/jcom_source.json`）。
- 既存の機種は、不足していたキャリア版を補い、型番を一覧の表記に合わせました。一覧に無い機種は新規に追加しました。
- 一覧は「J:COMモバイルで動作確認された端末」なので、各キャリアの全取扱機種とは限りません。
- **発売時期**は一覧に無いため、分かるものだけ入れています（不明は「—」）。ドコモ型番の世代（SC-51G の末尾G＝2026年 など）から年を補ったものもあります。
- **SIMロックの有無**は、発売時期または型番の世代から判定しています（ドコモ 2021/8/27・au／UQ／SB／Y! 2021/10/1以降はロックなし、楽天・SIMフリーは常にロックなし）。判定できないもの（Android One、ZTE a1 など）は「要判定」です。
- 2021年以降の機種で、以前に推測で入れていたキャリア版のうち、一覧に無いもの（19件）は取り消しました。

## 判定の考え方
出荷時のSIMロック有無は、各キャリアの「ロックなし販売」開始日で判定している。

| キャリア | ロックなしで販売された機種 |
|---|---|
| ドコモ | 2021/8/27以降に発売 |
| au・UQ | 2021/10/1以降に発売 |
| ソフトバンク・ワイモバイル | 2021/10/1以降に発売（2021/5/12以降の購入分は解除済で渡し） |
| 楽天モバイル | 全機種ロックなし |
| iPhone 13（2021/9/24発売） | 4キャリアとも発売時からロックなし |

## 型番の確認方法
- 各キャリアの公式サイト（ドコモ・au・ソフトバンク・ワイモバイル・楽天・サムスン・ソニー・シャープ）や価格サイトの検索結果で、機種名と型番が一致したものだけを記載した。
- 確認できなかった型番は空欄（一覧では「—」）にしている。機種名では検索できる。
- 公式サイトへ直接アクセスできない環境のため、検索結果の記載で確認している。**ドコモ・auは公式ページで一件ずつ再確認するのが望ましい**。

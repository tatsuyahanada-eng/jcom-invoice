# 開発ポートフォリオ（サンプル版データ）

業務の現場で実際に使うことを前提に開発した、Web アプリ（PWA）と Android アプリの実績まとめです。
後で受注用 LP に転用することを前提に、各作品を「課題 → 解決 → 主な機能 → 技術」の順で整理しています。

> 個人情報・社名・取引先名・サーバー情報・初期パスワードなどは削除または一般名に置き換えています。
> 画面に表示するデータはすべて架空のサンプルを使う前提です。

## 1. Case By Case — ツリー型 作業マニュアル

- **種別**：PWA ／ スマホ・PC
- **課題**：作業手順が人の頭の中や紙に散らばり、新人や応援者がすぐに正しい手順にたどり着けない。
- **解決**：大項目を選ぶと枝分かれし、チャットボットのように最終手順まで案内。みんなの入力をサーバーで 1 つのマニュアルとして蓄積・共有。

**主な機能**
- ツリー（親子）構造の手順マニュアル。並び替え・追加・削除、画像の貼り付け
- 複数人が同時に編集しても他人の入力を消さない、項目単位の保存（約30秒ごとの自動更新）
- アプリ内ログインと、ID ごと・大項目ごとの閲覧／編集権限（サーバー側でも判定）
- 作成者・更新者の自動記録、一定時間操作がないと自動ログアウト
- AI 検索（会話文で質問 → 該当手順を提示。該当なしのときはキーワード検索で探し直し）
- 「AI に相談」：会話を続けながら簡易手順をまとめる
- 作業完了報告書の記入サンプル表示
- 毎日の自動バックアップ（JSON）、サーバー移行手順つき
- 未接続時は端末内だけで動作（オフライン対応）

**技術**：HTML / CSS / JavaScript（PWA・Service Worker）、PHP（PDO）、MySQL / SQLite、Google Gemini API（ベクトル検索）、Excel 取り込み（SheetJS）

## 2. BI Dashboard — 個人事業向け 売上管理

- **種別**：PWA ／ スマホ・PC
- **課題**：売上・入金・請求書・申告の準備がバラバラのツールに分かれ、月末や年度末に手間がかかる。
- **解決**：売上を登録するだけで、日・月・年の集計、入金予定、請求書、確定申告の準備までつながる 1 つのアプリに。

**主な機能**
- ダッシュボード：日・月・年の切り替え、前月比・前年同月比、同じ日数での比較、累計ペース、顧客別・案件別の内訳
- 売上登録：税込／税抜入力の切り替え、月額案件の一括登録、検索・抽出、CSV 出力
- 入金予定：顧客ごとの締め日・支払日から自動計算（土日祝は前後の営業日にずらす）
- 入金照合：銀行明細 CSV（Shift_JIS 可）の取り込みと自動照合、振込手数料などの差額処理
- 請求書：顧客→案件→期間を選ぶと明細を自動作成、A4 プレビュー、PDF 保存・印刷、発行履歴
- 源泉徴収票の作成・確定申告の準備（管理者専用・再認証つき）
- 重複した顧客・案件の統合、データ点検機能
- デザイン切り替え（ダーク／ライト）、本番データとデモデータの切り替え

**セキュリティ**：bcrypt によるパスワード保存、ログイン試行回数の制限、HttpOnly / SameSite Cookie、独自ヘッダーによる不正書き込み防止、一定時間でのログアウト

**技術**：HTML / CSS / JavaScript（1 ファイル構成の PWA）、PHP 8（PDO）、MySQL / MariaDB

## 3. Library Portal — 更新履歴の版管理ポータル

- **種別**：PWA ／ スマホ・PC
- **課題**：グループ内で共有する資料・プログラム・アプリが「いつ・何が・誰によって」更新されたか追えない。
- **解決**：更新履歴を登録すると版数を自動で付け、本棚のような見た目で更新の歴史をひと目で分かるようにした。

**主な機能**
- 本棚ビュー：資料を横積みで表示。厚み＝更新回数、目盛り＝更新 1 件（区分ごとに色分け）、装丁の色＝種別
- 選ぶと見開きで開き、左ページに概要、右ページに年ごとの更新年表
- 一覧ビュー（表形式）との切り替え、検索
- 版数の自動採番（通常の更新 1.1→1.2、微修正 1.01→1.02、自動で繰り上がり）
- 更新ごとの添付ファイル（画像・PDF・ZIP・Excel・Word）＝過去版のファイルも取り出せる世代管理
- 管理者／閲覧のみの権限、複数アプリ共通のユーザー管理（シングルサインオン対応）

**技術**：PHP 8、MySQL 8、JavaScript、PWA（Service Worker・オフライン画面）

## 4. WorkBase Portal — 現場作業の業務ポータル

- **種別**：PWA ／ スマホ・PC
- **課題**：現場作業に必要な手順・マニュアル・設定ファイル・書類・連絡先が別々の場所にあり、探す時間と取り違えが発生する。
- **解決**：作業ごとに必要な情報を 1 ページにまとめ、作業結果の記録も同じ場所に残して後から探せるようにした。

**主な機能**
- 作業ページ：手順・マニュアル（PDF・動画・Web）・設定データ・書類（様式と記入例）・連絡先を集約
- 作業記録の登録と、月ごとの一覧・バックナンバー
- 大容量ファイルは FTP で置いて画面から登録（名称・用途・バージョンを表示し取り違えを防止）
- エクスプローラー風のファイル管理（一括アップロード、ドラッグ移動、フォルダ操作、分割アップロード・途中再開）
- ドラッグ＆ドロップでマニュアル登録（ページ数・再生時間を自動取得）
- ユーザー・権限管理（判定はすべてサーバー側）、変更履歴（いつ・誰が・何を）
- Web インストーラ付きの ZIP で、レンタルサーバーへ簡単に設置
- サーバーなしで動くデモ版あり

**技術**：HTML / JavaScript（1 ファイル構成の PWA）、PHP 8.1、MySQL / MariaDB、Python（配布パッケージ作成）

## 5. VertiCale — 縦型スケジュール管理

- **種別**：PWA ／ スマホ・PC
- **課題**：シフト・稼働日の申請や確定のやり取りが、チャットや紙で行われ、状況が分かりにくい。
- **解決**：休み希望・稼働可能日の申請から、仮出勤・確定までを縦型カレンダー 1 画面で管理。

**主な機能**
- 日ごとに「休み希望／稼働可／仮出勤／確定」を登録、まとめて登録
- 状態ごとの絞り込み表示（すべて・確定のみ・仮出勤のみ など）
- 今月の予定一覧、予定一覧・日付のコピー
- 音声または文字で予定を入力（話した内容を入力画面に反映）
- ToDo リスト
- カレンダーファイル（.ics）の作成、PDF 出力（A4 縦／横の切り替え）
- 合言葉による端末間の同期、通知、バックアップ保存

**技術**：HTML / CSS / JavaScript（PWA）、PHP（同期用 API）、Web Speech API

## 6. Today's Jobs — 訪問業務アシスタント

- **種別**：Android アプリ（APK）＋ ブラウザ版 ／ スマホ
- **課題**：1 日に複数件の訪問がある業務で、事前連絡・駐車場・訪問順の管理を紙やメモで行っていた。
- **解決**：スマホのカレンダーから当日の予定を取り込み、連絡状況・駐車場・作業状況を 1 画面で管理。

**主な機能**
- 当日の案件リスト（件数・時間・住所）、連絡済／駐車場確認／完了の集計
- 長押しドラッグで訪問順を入れ替え、全件を訪問順に回るルート案内
- 事前連絡の記録（通話済・留守電・SMS など、時刻・回数つき）、「直前連絡が必要」マーク
- 駐車場の有無と備考、注意事項メモ、写真の撮影・ファイル取り込み
- 本文中の電話番号を自動で見つけてタップ発信
- Google マップ／Yahoo! マップでの表示・ナビ
- 連携アプリ（定型リンク）：住所や電話番号を差し込んだリンクをボタン化
- メール定型文：フォルダ管理、差し込み項目（日付・時間・担当者・自作の項目）
- カレンダーは読み取り専用（予定を変更しない）、データは端末内のみに保存

**技術**：HTML / JavaScript（Web アプリ）、Android（Java・WebView）、カレンダー読み取り、GitHub Actions による APK 自動ビルド

## 7. APP UP FTP Manager — スマホ完結の FTP クライアント

- **種別**：Android アプリ（APK）＋ PC ブラウザ版（PWA）／ スマホ・PC
- **課題**：作った Web アプリの ZIP を解凍してサーバーへ上げるのに、PC が必要だった。
- **解決**：スマホ 1 台で「解凍 → 整理 → FTP アップロード」まで完結するアプリを開発。

**主な機能**
- 解凍：ZIP / LZH / TAR / tar.gz / tar.bz2 / tar.xz / RAR / 7z（Windows の日本語ファイル名も文字化けしない）
- 2 画面のファイルマネージャ（ローカル ⇔ サーバー）：作成・名前変更・削除・コピー・貼り付け・フォルダごと転送
- 複数サーバーの登録と切り替え（FTPS 推奨）
- 同じ名前のファイルがあるときの選択（上書き／新しければ上書き／名前を変えて保存／スキップ）
- 転送履歴、アップロード済みバッジと「更新あり」表示
- ローカル＝青、サーバー＝赤 の色分けで操作ミスを防止

**セキュリティ**：サーバー情報を AES-256-GCM で暗号化（マスターパスワード）、自動ロック、FTPS 既定で証明書を検証、権限はインターネットのみ、危険な書庫（zip slip）の検出

**技術**：HTML / JavaScript、Capacitor、Android（Java）、FTP/FTPS、Node.js（PC 版の中継）、自動テスト（44 項目）

## 8. Voice & Copy Paste（VoCP）— 音声入力と定型文

- **種別**：Android アプリ（APK）／ スマホ
- **課題**：報告や連絡の文章を、毎回スマホで手入力するのが手間。
- **解決**：話すだけで文字にする機能と、日付・時間・氏名を差し込める定型文を 1 つのアプリに。

**主な機能**
- 音声入力：押している間だけ／連続文字起こし（無音で途切れても自動で再開）
- 結果のコピー・テキスト保存・クリア、手動での編集
- 定型文：項目ごとにフォルダ分け、日付・時間（プルダウン）や氏名を差し込んでコピー
- 起動時の自動アップデート確認（上書きインストール対応）
- 外部 API キー不要（端末標準の音声認識を使用）

**技術**：Kotlin、Jetpack Compose（Material 3）、Android SpeechRecognizer、GitHub Actions による APK 自動ビルド

### PWA-01　Case By Case
**質問に答えて進む、ツリー型の作業マニュアル**

- **選ぶだけで手順にたどり着く**：「どんな症状か」を順に選ぶと、その場で必要な手順だけが表示されます。
- **みんなで育てるマニュアル**：複数人が同時に書き足しても互いの入力を消しません。作成者・更新者も自動で記録。
- **AI に聞いて探せる**：「ルーターが赤く光る」のような話し言葉で質問すると、該当する手順を探します。

画面イメージ：大項目を選ぶ（スマホ） / 最終手順の表示（スマホ） / PC での表示（PC）


### PWA-02　BI Dashboard
**売上の登録から、入金照合・請求書・申告の準備までひとつに**

- **今月の調子がひと目で**：前月・前年と「同じ日数」で比べるので、月の途中でも正しく比較できます。
- **入金漏れに気づける**：締め日・支払日から入金予定を計算し、銀行明細の CSV と自動で突き合わせます。
- **請求書もその場で**：顧客と期間を選ぶと明細を自動で作成。A4 の PDF で保存・印刷できます。

画面イメージ：月次の売上概要（スマホ） / 締め日ごとの入金照合（スマホ） / PC のダッシュボード（PC） / 請求書の作成とプレビュー（PC）


### PWA-03　Library Portal
**更新の歴史が「本棚」でひと目で分かる版管理ポータル**

- **見た目に意味がある本棚**：厚み＝更新回数、目盛り＝更新 1 件、色＝種類。眺めるだけで更新の多さが分かります。
- **版数は自動で採番**：通常の更新は 1.1→1.2、微修正は 1.01→1.02。繰り上がりも自動です。
- **過去の版も取り出せる**：更新ごとに添付したファイルが残るので、前の版にもすぐ戻れます。

画面イメージ：本棚ビュー（スマホ） / 資料の詳細（スマホ） / PC の本棚ビュー（PC） / 見開きと更新年表（PC）


### PWA-04　WorkBase Portal
**現場作業に必要な情報と作業記録を 1 か所に**

- **作業ページで全部そろう**：手順・マニュアル（PDF・動画）・設定データ・書類の記入例・連絡先を 1 画面に。
- **大きなファイルも安全に配布**：FTP で置いたファイルを画面から登録。名称・用途・バージョンを並べて取り違えを防ぎます。
- **誰が何を変えたか残る**：作業・ファイル・ユーザーの変更を履歴として記録します。

画面イメージ：作業一覧（スマホ） / 作業ページ（スマホ） / PC の作業ページ（PC）


### PWA-05　VertiCale
**休み希望から出勤確定までを 1 画面で管理する縦型カレンダー**

- **縦に流れるカレンダー**：スマホで縦にスクロールするだけで 1 か月の予定と空き時間帯が見渡せます。
- **仮と確定を見分けられる**：仮出勤は点線、確定は塗りつぶし。休み希望・稼働可も色で区別します。
- **話して予定を登録**：音声で話した内容を入力画面に反映できます。

画面イメージ：月のカレンダー（スマホ） / ToDo リスト（スマホ） / PC での表示（PC）


### APK-01　Today's Jobs
**カレンダーの当日予定を取り込み、訪問業務を効率よく**

- **今日やることが一覧に**：訪問予定・連絡済・駐車場確認・完了の件数が一番上で分かります。
- **連絡の記録がワンタップ**：通話済・留守電・SMS を時刻つきで記録。電話番号は本文から自動で見つけます。
- **カレンダーは変更しない**：読み取り専用なので、アプリで編集しても元の予定はそのままです。

画面イメージ：当日の案件一覧（スマホ） / 案件の詳細と連絡記録（スマホ） / メール定型文（スマホ）


### APK-02　APP UP FTP Manager
**スマホ 1 台で、解凍・整理・FTP アップロードまで**

- **色で迷わない 2 画面**：手元（青）とサーバー（赤）を色分け。送る方向をボタンの色でも示します。
- **日本語のファイル名も安心**：ZIP・LZH・RAR・7z などを解凍。Windows で作った書庫も文字化けしません。
- **接続情報は暗号化**：サーバーの情報はマスターパスワードで暗号化して保存。通信は FTPS が標準です。

画面イメージ：マスターパスワードの設定（スマホ） / 手元のファイル（青）（スマホ） / サーバー側（赤）（スマホ） / PC ブラウザ版（PC）


### APK-03　Voice & Copy Paste
**話すだけで文字に。差し込み定型文もワンタップでコピー**

- **2 つの文字起こし方**：押している間だけ、または止めるまで連続。無音で途切れても自動で再開します。
- **定型文に差し込んでコピー**：日付・時間はプルダウンで選ぶだけ。できた文章をそのままコピーできます。
- **キー不要ですぐ使える**：端末標準の音声認識を使うので、外部サービスの登録はいりません。

画面イメージ：音声入力（イメージ）（スマホ） / 定型文（イメージ）（スマホ）

# サーバー作業チェックアプリ

各サーバーごとの作業進捗を「縦＝サーバー、横＝チェック項目」の表でチェックしていく Android アプリです。

## ダウンロード
`ServerChecklist.apk` を Android 端末にダウンロードしてインストールしてください（「提供元不明のアプリ」の許可が必要です）。Android 7.0 以上。

## 主な機能
- 表のセルをタップでチェック（時刻を記録）。オレンジ枠が各サーバーの「次の作業」
- 順番どおりモード（初期ON）：前の作業が終わるまで次はチェック不可
- セルを長押しで、そのチェック項目の備考を入力（備考ありのセルは右上に紫の印）
- サーバー名タップで詳細（チェック時刻一覧・メモ・次の作業を完了）
- 「▶ 次へ」で未完了の最初のサーバーへジャンプ／検索・未完了/完了フィルタ
- 設定 › チェック項目：使う項目をスイッチで選択、≡ドラッグ or ▲▼で並び替え、追加・名称変更・削除
- 設定 › サーバー：連番追加（例 308-2-01〜16）、名前の貼り付け追加、並び替え
- 設定 › その他：CSV共有、バックアップ／復元、チェッククリア、初期サンプルに戻す

初期サンプル：サーバー96台（部屋 304・306・302 × 2列/3列 × 01〜16、例 304-2-01）、項目26件（うち14件を使用中）。

## ビルド
```
ANDROID_HOME=/path/to/sdk ./build.sh   # platforms;android-34, build-tools;34.0.0 が必要
```
画面は `app/assets/index.html`（ブラウザでも開けます）。署名鍵 `release.keystore` を同じものにしておくと上書き更新できます。

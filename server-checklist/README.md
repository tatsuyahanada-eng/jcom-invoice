# CDU Check Tool（サーバー作業チェックアプリ）

各サーバーごとの作業進捗を「縦＝サーバー、横＝チェック項目」の表でチェックしていく Android アプリです。

## ダウンロード
`ServerChecklist.apk` を Android 端末にダウンロードしてインストールしてください（「提供元不明のアプリ」の許可が必要です）。Android 7.0 以上。

## 主な機能
- 表のセルをタップで「済」（時刻を記録）。終わった作業から順不同で付けられます
- 順番どおりモード（設定で選択、初期OFF）：ONにすると前の作業が終わるまで次はチェック不可
- セルを長押しで、済／未・作業日時（日付・時刻）・備考を編集（備考ありのセルは右上に紫の印）
- 上部のボタンで部屋番号（サーバー名の最初の「-」より前）ごとに表示を切り替え
- 左列はラック番号、その下にリアドア番号（ラック番号タップの詳細画面で入力）
- ラック番号の左のチェックで作業対象を選択（対象外は灰色で操作不可・進捗にも数えない）。設定 › サーバーで部屋ごとにまとめて設定、Excel では「対象」列（○）
- マスの長押しで「問題事項」も入力可。問題事項があるラックは、ラック番号の左の緑チェックが黄色になり、マスの左上にも橙の印（上部の「問題」で絞り込み、Excel では「問題事項」シート）
- 一覧の上部に「番号順に並び替え」（押すたびに昇順／降順）と「対象のみ表示」（対象外を隠す）ボタン
- 各作業項目の見出しに「残 N」（表示中の部屋の対象ラックのうち、済でない数。0 なら「完了」）
- ラック番号タップで詳細（チェック時刻一覧・メモ・次の作業を完了）
- 「▶ 次へ」で未完了の最初のサーバーへジャンプ／検索・未完了/完了フィルタ
- 設定 › チェック項目：使う項目をスイッチで選択、≡ドラッグ or ▲▼で並び替え、追加・名称変更・削除
- 設定 › サーバー：番号順（昇順・降順）の並び替え、連番追加（例 308-2-01〜16）、名前の貼り付け追加、並び替え
- 設定 › データ共有：サーバー名・作業項目・進捗を1ファイル（.json）で LINE・メール等に共有、受け取ったファイルを取り込み（置き換え／合算を選択）
- 設定 › データ共有 › Excel：画面と同じ見た目の .xlsx を書き出し。パソコンで直した Excel をそのまま取り込み可能（済＝「済」または日時、空欄＝未、備考は「備考」シート）
- 設定 › その他：表示設定、チェッククリア、初期サンプルに戻す

初期サンプル：サーバー96台（部屋 304・306・302 × 2列/3列 × 01〜16、例 304-2-01）、項目26件（うち14件を使用中）。

## ビルド
```
ANDROID_HOME=/path/to/sdk ./build.sh   # platforms;android-34, build-tools;34.0.0 が必要
```
画面は `app/assets/index.html`（ブラウザでも開けます）。署名鍵 `release.keystore` を同じものにしておくと上書き更新できます。

同梱ライブラリ：ExcelJS（MIT）、JSZip（MIT）。ライセンスは `app/assets/*.LICENSE.txt`。

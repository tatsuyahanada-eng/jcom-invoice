# Today's Jobs

Googleカレンダーから当日の予定（訪問案件）を取り込み、現場を効率よく回るための業務補助アプリです。スマホでの利用を前提にしています。

## 主な機能

| 機能 | 内容 |
|---|---|
| 案件リスト | その日の件数・時間・件名・住所を一覧表示。上部に「連絡済 / 駐車場確認 / 完了」の集計 |
| 訪問順の入れ替え | カードを**長押し → そのまま上下にドラッグ**。編集モードでは ↑↓ ボタンでも変更可 |
| 直前連絡が必要のマーク | 案件の詳細で「直前連絡が必要」をオンにすると、トップ画面に**赤い目立つ印**（バナー・日付の横・案件カード）が出ます。通話済にすると緑の「直前連絡 済」に変わります |
| 事前連絡ステータス | 通話済 / 留守電 / コールのみ / SMS をタップで記録（時刻・回数つき履歴。誤タップは×で取消） |
| 駐車場 | 未確認 / あり / なし ＋ 備考欄 |
| 注意事項メモ | 自由記入（自動保存） |
| 作業ステータス | 未着手 / 作業中 / 完了（完了で集計・進捗バーに反映） |
| 編集 | 下部「編集」→ 不要な案件をゴミ箱で削除（直後なら「元に戻す」可）。カードをタップで件名・時間・住所・電話を修正 |
| 手動追加 | カレンダーにない案件を追加 |
| 電話・ナビ | 詳細画面から発信、Googleマップでナビ、住所コピー。「ルート案内」で全件を訪問順に経由するルートを表示 |
| 地図で住所を見る | 案件の詳細画面の「予定の内容」→「住所」の欄から **Googleマップ / Yahoo!マップ** を「アプリで開く」または「Web」で表示。アプリ未インストール時はブラウザで開きます |
| 連携アプリ（定型リンク） | 設定で「名前＋URL」を登録すると、**画面の一番上**にボタンとして並びます（業務開始前に使うアプリなどに）。URLに `{address}` などを入れると、「次の訪問」の案件の情報が差し込まれます |
| 翌日の読み込み | 日付の ‹ › で切り替えて「読み込む」。日付が変わると自動で当日表示に切り替わります |

### 電話番号のタップ発信
本文・メモ・駐車場の備考などに書かれた電話番号（090/080/070/050 や、03・048 など市外局番で始まる10〜11桁）は、自動で見つけてタップすると電話アプリが開きます。案件の詳細の「事前連絡」欄の上に、見つかった番号が「電話をかける」ボタンとして並び、予定の内容の本文中の番号もタップできます。全角数字や「03(1234)5678」のような書き方にも対応しています。郵便番号や日付は電話番号として扱いません。

### メール定型文（上部メニューの「メール」）
案件ごとにメールの定型文を登録し、差し込み項目を入れてコピーしたり、端末のメールアプリで送信画面を開いたりできます。

- **フォルダ構造**：案件名でフォルダを作り、その中に定型文や、さらに別のフォルダを入れられます（例：大宮DC 水冷ドア案件 ＞ 到着連絡／作業完了報告）。上の「PATH」から上の階層に戻れます。
- **差し込み項目（変数）**：件名・本文に `{日付}` `{時間1}` `{時間2}` `{担当者}` を入れておくと、使うときに入力欄が出て、その値が差し込まれます。
  `{作業内容}` `{部屋番号}` のように、自分で作った名前の変数も使えます（「＋ 変数を作る」）。
  日付・時間は一覧から選ぶか、そのまま入力できます。担当者や自作の変数は、前回入力した値を覚えています。未入力の項目は `{担当者}` のまま残るので、入れ忘れに気づけます。
- **使い方**：定型文をタップ → 項目を入力 → 「メールを作成して送信」で端末のメールアプリが宛先・件名・本文入りで開きます。「本文だけコピー」も使えます。件名・本文はその場で手直しもできます。
- **登録・編集**：メール画面の右上のペンで編集モードにすると、フォルダ・定型文の追加、名前や内容の変更、並べ替え、削除ができます。最初は「サンプルの定型文を入れて試す」で動きを確認できます。
- 登録内容はこの端末に保存されます。

### カレンダーの予定は変更されません（読み取り専用）
このアプリはカレンダーを**読み取るだけ**です（Googleは読み取り専用の権限、Androidは「カレンダーの読み取り」権限のみ）。アプリ内で案件を削除・編集・上書き取り込みしても、Googleカレンダー／端末のカレンダーの予定は変更・削除されません。

### 取り込み済みの日を上書き取り込みする
すでに取り込み済みの日で「読み込み」を押すと、確認のポップアップが出ます。
- **上書き取り込みする**：その日の取り込み済みの案件をいったん破棄し、カレンダーの内容で入れ替えます。連絡状況・駐車場・メモ・並び順・削除の記録は消えます（手動で追加した案件は残ります）。
- **入力内容を残して更新のみ**：入力内容はそのまま、追加・変更された予定だけを反映します（下記の「再読み込みの挙動」）。
- **キャンセル**：何もしません。

### 再読み込み（同期）の挙動
- 同じ日を再読み込みしても、**並び順・連絡状況・駐車場・メモは保持**されます。
- 新しく増えた予定は末尾に追加されます。
- 手動で削除した予定は、再読み込みしても復活しません（設定 →「表示中の日付のデータをリセット」で元に戻せます）。
- アプリ内で編集した項目は、カレンダー側の内容で上書きされません。
- カレンダー側で消えた予定には「カレンダーから削除済」ラベルが付きます。

### カレンダー予定の書き方のコツ
- 住所は予定の「場所」欄に入れるのが確実です。説明欄に `住所: 〜` と書いても認識します。
- 説明欄の電話番号（`090-1234-5678` 等）を自動で拾い、発信ボタンに設定します。

## 連携アプリ（定型リンク）の書き方

設定 →「連携アプリ（定型リンク）」で登録します。`https://` のWebページのほか、アプリのURLスキーム（`xxx://` や `sms:` など）も使えます。

| 差し込み記号 | 入る内容 |
|---|---|
| `{address}` | 住所 |
| `{tel}` | 電話番号 |
| `{title}` | 件名 |
| `{date}` | 日付（例: 2026/9/30） |
| `{start}` | 開始時刻 |
| `{memo}` | 注意事項メモ |
| `{parking}` | 駐車場（あり/なし＋備考） |

例:
- Waze でナビ … `https://waze.com/ul?q={address}&navigate=yes`
- Appleマップ … `https://maps.apple.com/?q={address}`
- LINEで送る … `https://line.me/R/msg/text/?{title}%0A{address}`
- SMSを作成 … `sms:{tel}`

`{address}` や `{tel}` を使ったボタンは、「次の訪問」の案件に住所・電話番号がない場合は押せない状態になります。`{date}` だけを使うボタンなら、案件がなくても使えます。

## 地図アプリの起動について
- Googleマップ: iPhone は `comgooglemaps://`、Android はアプリを直接指定して起動します。
- Yahoo!マップ: iPhone は `yjmap://search?query=住所`、Android はアプリ（`jp.co.yahoo.android.apps.map`）を直接指定して起動します。Web版は `https://map.yahoo.co.jp/search?q=住所` です。
- Android はアプリが無ければ自動でブラウザ表示に切り替わります。iPhone はアプリが起動しなかった場合「ブラウザで開く」ボタンを表示します。

## データの保存先
入力内容（連携アプリの登録を含む）はその端末のブラウザ（localStorage）に日付ごとに保存されます。サーバーには送信しません。30日より古いデータは自動削除されます。
※ 別の端末・別のブラウザとは共有されません。

## セットアップ（Googleカレンダー連携）

静的ファイル（`index.html` ほか）を **HTTPS** のWebサーバーに置くだけで動きます。
Googleカレンダーを読むために、一度だけ OAuth クライアントIDを作成します。

1. [Google Cloud Console](https://console.cloud.google.com/) でプロジェクトを作成
2. 「APIとサービス」→「ライブラリ」で **Google Calendar API** を有効化
3. 「OAuth 同意画面」を設定（User Type: 外部 / テストユーザーに自分のGoogleアカウントを追加）
   - スコープ: `.../auth/calendar.readonly`（読み取り専用）
4. 「認証情報」→「認証情報を作成」→「OAuth クライアントID」
   - 種類: **ウェブアプリケーション**
   - 承認済みの JavaScript 生成元: アプリを置くURLのオリジン（例: `https://example.com`）
5. 発行されたクライアントID（`xxxx.apps.googleusercontent.com`）を、アプリの **設定 → OAuth クライアントID** に貼り付けて「Googleに接続」
6. 読み込むカレンダーを選択（共有されている業務用カレンダーも選べます）

> クライアントIDなしでも「デモデータで試してみる」から操作感を確認できます。

## ホーム画面に追加
スマホのブラウザで開き「ホーム画面に追加」すると、アプリのように全画面で起動できます。

## Androidアプリ（APK）

同じWebアプリを、Android用アプリ（`todays-jobs/android/`）としても配布できます。

### ダウンロードとインストール
1. GitHub の Releases から **`apk-latest`** を開き、`today'sjobs.apk`（ファイル名は環境により `today.sjobs.apk` と表示されることがあります）をダウンロード
   - もしくは、Actions の最新の実行 → Artifacts の `todays-jobs-apk`（zipの中に `today'sjobs.apk`）
2. ダウンロードしたAPKをタップしてインストール（初回は「提供元不明のアプリ」の許可が必要です）
3. 2回目以降は、同じ手順で上書きインストールできます（署名が同じため、データも残ります）

### 端末のカレンダーから読み込む（アプリ版の標準）
- アプリの「読み込み」を押すと、初回だけカレンダーの権限の確認が出ます。許可すると、**スマホに同期されているカレンダー**から当日の予定を読み込みます。
- **Googleへのログインも、Google Cloudの設定も、審査も不要**です。会社のアカウントでも個人のアカウントでも、複数のアカウントが混ざっていても使えます。
- 読み込むカレンダーは、設定 →「カレンダー連携」で**カレンダーごとにチェックして選べます**（例：「その他業務」「くらしのマーケット」だけ）。「全選択」「全解除」も使えます。複数選ぶと、各案件にカレンダー名が表示されます。Googleでログインする場合も同じく、カレンダーごとに選べます。
- 辞退した予定は読み込みません。繰り返しの予定も、その日の分が正しく入ります。
- 予定が出てこない場合は、スマホの「Googleカレンダー」アプリなどで、そのアカウントが同期されているか確認してください。
- Androidアプリ専用です（iPhoneやブラウザ版では使えません）。

### Googleカレンダー連携（アプリ版・任意）
設定で「Googleでログイン」に切り替えると、端末の同期を使わずGoogleのAPIで直接読み込めます。
アプリ版は端末のGoogleアカウントでログインします。事前に一度だけ、Google Cloud Console で次を設定してください。

1. 上記「セットアップ」の 1〜3（プロジェクト作成・Calendar API有効化・OAuth同意画面）
2. 「認証情報」→「OAuth クライアントID」→ 種類 **Android**
   - パッケージ名: `jp.todaysjobs.app`
   - SHA-1 証明書フィンガープリント: `90:1D:58:B6:3D:A9:DC:CC:7C:D7:95:E5:33:BA:D0:6E:97:FB:54:4B`
3. アプリの「読み込み」を押すとGoogleのログイン・許可画面が出ます（クライアントIDの入力は不要）

### ビルドについて
`todays-jobs/` 配下を push すると GitHub Actions（`.github/workflows/build-apk.yml`）が自動でAPKをビルドし、Releaseを更新します。

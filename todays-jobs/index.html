    カレンダー連携

    スマホに同期されているカレンダー（Googleカレンダーアプリなど）から、直接予定を読み込みます。Googleへのログインや設定は不要です。

    チェックを付けたカレンダーの予定だけを読み込みます（例：「その他業務」「くらしのマーケット」など）。

    未接続

    Google Cloud Console で作成した「ウェブアプリケーション」のクライアントIDを入力してください（手順は README 参照）。

    Androidアプリでは、端末のGoogleアカウントでログインします（クライアントIDの入力は不要です）。

    終日の予定を除外休み・メモ等の終日予定を読み込まない

    指定すると、件名にいずれかのキーワードを含む予定だけを取り込みます。

    🔒 このアプリはカレンダーを読み取るだけです。アプリ内で案件を削除・編集しても、カレンダーの予定は変更・削除されません。

    ルート案内

    完了済みの案件をルートから除外

    ¥売上（任意）

    金額は税込みで入力します。その日の合計（日当＋スポット）を税込みで表示し、税抜き・消費税は参考として割り戻して出します。

    ¥売上管理（管理者）

    月ごとの売上の合計の確認と、CSV・PDFでの出力ができます。管理パスワードが必要です（初回だけ設定します）。

    売上の記録は、30日を過ぎた自動削除や「データの範囲削除」をしても残ります。

    連携アプリ（定型リンク）

    名前とURLを登録すると、画面の一番上にボタンとして並びます（業務開始前に使うアプリなどに）。URLに差し込み記号を入れると、「次の訪問」の案件の情報が入ります。

      ボタンをタップするとカーソル位置に差し込み記号が入ります（例: {address} → その案件の住所）。

      データ

      入力した連絡状況・駐車場・メモは、この端末のブラウザ内に日付ごとに保存されます（30日経過で自動削除）。容量が気になるときは、下で範囲を選んでまとめて削除できます。

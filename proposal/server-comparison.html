3. ドメイン取得のポイント

  • .co.jp：日本で登記した会社だけが取得でき、1社につき1つ。設立予定の会社は登記の6か月前から仮登録できます。
  • .jp：日本国内に住所がある個人・団体が取得できます。.com は誰でも取得できます。
  • 名義は担当者個人ではなく会社名義で。退職などで管理できなくなるのを防ぎます。
  • 自動更新を必ず設定します。.jp・.co.jp は期限が切れると更新できず、同じドメインを取り戻せないことがあります。
  • 取得時の安い料金は初年度だけのことが多く、2年目以降は更新料金で考えます。

4. メールアドレス取得のポイント

  • 独自ドメインをサーバーに設定すると、info@・sales@・個人名@ などを作れます。作成数は表の各社とも実質無制限です（ConoHa は要確認）。
  • メールの料金はサーバー料金に含まれます。Outlook・スマホのメールアプリ・ブラウザ（Webメール）で読めます。
  • 迷惑メール扱いを防ぐ設定（SPF・DKIM・DMARC）を最初に行います。設置時に当方で対応できます。
  • 社員が多くメールを重視する場合は、Google Workspace などのメール専用サービスを組み合わせる方法もあります（1人あたり月額の別料金）。

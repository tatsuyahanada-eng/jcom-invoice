# ネタ帳（SE の日常 × AI）

SE の仕事や生活の中で「AI でこうしたら楽になった」「これアプリにできそう」と思ったことを、
**1行ずつ `- ` で始めて**書き足してください。上にあるものから順に、月・木の投稿に1件ずつ使われます。
（使ったメモは履歴で管理されるので、消さなくて大丈夫です）

- 勤務先・顧客・案件・同僚が特定できることは書かない（投稿でも伏せるよう指示していますが、書かないのが一番確実）
- 起きたことをそのまま短く。盛らなくて OK。数字があれば実際の数字だけ
